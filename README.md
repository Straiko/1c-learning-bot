# 🎓 1C Screenshot Code Trainer (Telegram Bot)

Интерактивный Telegram-бот для тренировки и проверки написания кода 1С:Предприятие со скриншота (загрузка контрагентов из JSON в справочник).

---

## 🚀 Ключевые возможности

### 1. ✍️ Интерактивный тренажер написания кода (Code Practice & Automated Tests)
Вы пишете код прямо в чате Telegram. Бот автоматически разбирает ваш ввод строчка за строчкой:
* 🌐 **Определение контекста среды:** четко указывает, выполняется ли секция в `&НаКлиенте` (браузер / тонкий клиент) или `&НаСервере` (сервер приложений 1С).
* 🔍 **Детальная диагностика ошибок:**
  - Указывает точный номер строки с ошибкой.
  - Показывает, что написали вы, и что ожидалось по скриншоту.
  - Объясняет, в чем именно ошибка: опечатка в имени метода/переменной, пропущенный параметр, отсутствие директивы `&НаКлиенте`/`&НаСервере`, неверные кавычки или пропущенные строки.
* 📋 **Разбивка на 5 секций:**
  1. Клиентский диалог выбора файла (`&НаКлиенте`, `ДиалогВыбораФайла`, `ОписаниеОповещения`).
  2. Проверка выбора и чтение файла (`&НаСервере`, `ТекстовыйДокумент`, `ПрочитатьЗначениеJSON`).
  3. Цикл обхода массива и поиск в базе (`Справочники.Контрагенты.НайтиПоКоду`).
  4. Заполнение реквизитов, `.Записать()` и ветка `Иначе` с `Сообщить(...)`.
  5. Полный экзамен — воспроизведение обеих процедур со скриншота целиком!

---

### 2. Дополнительные обучающие модули
* **📖 Пошаговый разбор (5 шагов):** подробные пояснения к каждой конструкции.
* **🧠 Тест (Квиз из 6 вопросов):** проверка понимания механизмов платформы 1С.
* **🐛 Тренажер «Найди баг»:** анализ архитектурных нюансов клиент-серверного разделения.
* **📄 Исходный код со скриншота:** оригинальный текст кода.

## 🛠 Запуск бота

### 1. Токен бота
1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Создайте нового бота (`/newbot`) и скопируйте API токен.

### 2. Настройка `.env`
Создайте `.env` в папке проекта:
```bash
cp .env.example .env
```
Укажите ваш токен:
```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
```

### 3. Запуск
```bash
./run.sh
```
или:
```bash
python3 main.py
```
