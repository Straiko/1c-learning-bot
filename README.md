# 🎓 1C Code Learning Telegram Bot

Интерактивный Telegram-бот для быстрого и глубокого освоения кода 1С:Предприятие со скриншота (загрузка контрагентов из JSON через диалог выбора файла).

## 🚀 Возможности бота

1. **📖 Пошаговый разбор (5 шагов / карточек):**
   - Урок 1: Архитектура 1С и контексты `&НаКлиенте` vs `&НаСервере`.
   - Урок 2: Асинхронные методы диалога (`ДиалогВыбораФайла`, `ОписаниеОповещения`).
   - Урок 3: Чтение файла и десериализация JSON в 1С.
   - Урок 4: Справочники: Поиск (`НайтиПоКоду`) и Создание (`СоздатьЭлемент`, `Записать`).
   - Урок 5: Подводные камни и архитектурные дефекты.

2. **🧠 Интерактивный квиз (Тестирование):**
   - 6 вопросов с вариантами ответов.
   - Мгновенная проверка и подробное объяснение каждого ответа.
   - Подсчет баллов и итоговый вердикт.

3. **🐛 Тренажер «Найди баг»:**
   - Практические кейсы с анализом фрагментов кода на наличие ошибок клиент-серверного взаимодействия и производительности.

4. **📄 Просмотр кода и JSON:**
   - Исходный код со скриншота.
   - Пример структуры JSON.
   - **⭐ Эталонная реализация (Best Practice)** с передачей файла во временное хранилище и правильным парсером `ЧтениеJSON`.

## 🛠 Запуск бота

### 1. Получение токена:
1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям.
3. Скопируйте полученный API токен.

### 2. Настройка `.env`:
Создайте файл `.env` в директории бота (или отредактируйте `.env.example`):
```bash
cp .env.example .env
```
Укажите ваш токен:
```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
```

### 3. Запуск:
```bash
cd /home/root2506/1c-learning-bot
./run.sh
```
или напрямую:
```bash
python3 main.py
```
